# PricePulse – E-Commerce Price & Discount Intelligence System

## Project Overview
PricePulse is a SQL-based e-commerce data analysis project developed using MySQL. It organizes product, seller, customer, order, pricing, and review information to analyze product prices, recorded discounts, sales activity, and customer ratings.

## Objectives
- Organize e-commerce data using relational database tables.
- Analyze product prices and recorded discounts.
- Summarize orders and sales activity.
- Compare product ratings and reviews.
- Practice SQL for business data analysis.

## Technologies Used
- MySQL 8.0
- MySQL Workbench
- SQL

## Database Tables
1. Categories
2. Sellers
3. Customers
4. Products
5. Price History
6. Orders
7. Order Items
8. Reviews

## SQL Concepts Used
- Database and table creation
- INSERT and SELECT statements
- WHERE, LIKE, BETWEEN, and DISTINCT
- JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate functions: COUNT, SUM, AVG, MIN, and MAX
- Subqueries
- Primary keys and foreign keys

## Example Business Questions
- Which products have the highest prices?
- What discounts are recorded for products?
- Which categories contain the most products?
- What is the total order value?
- Which products have the highest average ratings?
- Which customers have placed orders?

## Project Scope
This project uses sample e-commerce data for SQL practice and analysis. Live price collection, automated alerts, and price forecasting are not currently implemented.
